Reprocess voyage with current algorithms runs the recorded sensor inputs through the currently installed AJRM Marine software and saves a new calculated voyage result. Replay saved voyage plays an already saved result without recalculating or recording it. Stop playback ends that read-only replay. Both operations run server-side, so the browser may be closed. Reprocessing automatically stops and builds its ZIP at verified input EOF. Finalise now remains as a fallback after verified EOF; Interrupt replay preserves a partial result in an explicitly incomplete, unverified ZIP. A voyage without current sensor input or a completed saved result cannot use the corresponding action.
